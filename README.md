# CodeAlpha Data Analytics Internship Projects

This repository contains my projects completed during the CodeAlpha Data Analytics Internship.

The projects demonstrate practical skills in Python, web scraping, data cleaning, exploratory data analysis, and data visualization.

## Projects

### Task 1: Web Scraping

Scraped book information from the Books to Scrape website using Python, Requests, and BeautifulSoup.

The following information was collected:

- Book Title
- Price
- Rating
- Availability
- Product URL

The scraped data was stored in `books_dataset.csv`.

### Task 2: Exploratory Data Analysis

Performed exploratory data analysis on the scraped book dataset using Pandas, NumPy, Matplotlib, and Seaborn.

The analysis includes:

- Dataset structure
- Data types
- Missing value analysis
- Duplicate detection
- Statistical summary
- Price analysis
- Rating analysis
- Price and rating relationship
- Data cleaning
- Feature engineering

The cleaned dataset is available as `books_cleaned.csv`.

### Task 3: Data Visualization

Created visualizations to communicate patterns and insights from the book dataset.

The visualizations include:

- Book Rating Distribution
- Book Price Distribution
- Book Price Box Plot
- Average Price by Rating
- Book Price vs Rating
- Top 10 Most Expensive Books
- Price and Rating Correlation
